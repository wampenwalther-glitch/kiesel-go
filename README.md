# Kiesel Go-Schule

Go lernen von null an, direkt im Browser: Tutorial mit Meisterprüfungen, 63 Trainingsaufgaben und Partien gegen eine eigene Go-Engine (MCTS + RAVE, ohne neuronale Netze).

**Spielen:** https://wampenwalther-glitch.github.io/kiesel-go/

Alles steckt in einer einzigen Datei (`index.html`) und läuft auch offline. Fortschritt wird nur im Browser des jeweiligen Geräts gespeichert.
